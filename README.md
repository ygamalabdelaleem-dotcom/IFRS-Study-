# منظّم مذاكرة IFRS

تطبيق ويب عربي لتنظيم مذاكرة IFRS والتحضير للامتحان (DipIFR أو SBR أو خطة مخصصة)، مبني على فكرة **«مهمة واحدة دلوقتي»**.

الرحلة: **المهمة ← جلسة مذاكرة بالتايمر ← حل سؤال ← تسجيل الخطأ ← المراجعة التالية.**

## التشغيل

- **أونلاين:** https://ygamalabdelaleem-dotcom.github.io/IFRS-Study-/
- **على الجهاز:** نزّل الريبو وافتح `index.html` في أي متصفح حديث. مش محتاج سيرفر ولا إنترنت ولا حساب.

البيانات بتتحفظ في متصفحك بس (localStorage). صدّر نسخة احتياطية من **الإعدادات ← البيانات** بشكل دوري.

## الأقسام

| القسم | المحتوى |
|---|---|
| النهارده | المهمة الحالية + التايمر + المراجعات المستحقة + وضع التركيز |
| الخطة | قائمة بالأسابيع أو تقويم، نقل وتأجيل وتعديل المدة، وإعادة توزيع بمعاينة |
| المعايير | صفحة لكل معيار: مصادرك، مهامه، أسئلته، بطاقاته، أخطاؤه |
| البطاقات | مراجعة متباعدة (SM-2) مع بحث وفلترة وإضافة وتعديل وملاحظات |
| الأسئلة | بنك أسئلة، تدريب، محاولة بالوقت، امتحان تجريبي، استيراد |
| الأخطاء | سبب الخطأ، التصحيح، إعادة المحاولة، والتحويل لمهمة أو بطاقة |
| التقدم | الالتزام · التغطية · الإتقان · المراجعة + ملخص أسبوعي |
| الإعدادات | المؤهل والتواريخ والوقت والجلسات والمظهر والنسخ الاحتياطي |

## تحديث المحتوى

كل المحتوى موجود في `content/content.js`. عدّل الملف ده وغيّر `contentVersion` و `lastReviewed`، ومن غير ما تلمس باقي التطبيق. أي معلومة مش متأكد منها علّمها `needsReview`.

### صيغة استيراد الأسئلة

```json
{ "questions": [
  { "id": "my-01", "type": "mcq", "std": "ifrs16", "difficulty": 2, "marks": 2,
    "prompt": "نص السؤال", "options": ["أ", "ب", "ج"], "correct": 1, "explanation": "..." },
  { "id": "my-02", "type": "numeric", "std": "ias36", "marks": 3, "prompt": "...", "answer": 120, "tolerance": 1, "model": "الحل" },
  { "id": "my-03", "type": "written", "std": "ias37", "marks": 4, "prompt": "...", "model": "...",
    "rubric": [{ "point": "ذكر الشروط", "marks": 2 }, { "point": "الاستنتاج", "marks": 2 }] }
] }
```
- `correct` بيبدأ من 0.
- `std` هو معرف المعيار زي `ifrs16` أو `ias36`، والقائمة كاملة في `content.js`.
- الأسئلة اللي عندها `id` موجود قبل كده بتتجاهل، عشان ما يحصلش تكرار.

## تنبيهات مهمة

- **المنهج لم يتم التحقق منه مقابل المصادر الرسمية.** قوائم المعايير والأوزان تقديرية. راجع *Examinable documents* و *Syllabus* لدورتك على موقع ACCA.
- **IFRS 18:** صدر في أبريل 2024 ويسري من 1 يناير 2027 بدل IAS 1. حسب قاعدة ACCA، المعيار اللي يصدر قبل 1 سبتمبر بيدخل امتحانات السنة اللي بعدها، حتى لو تاريخ سريانه لسه ماجاش. يعني سريان المعيار حاجة ودخوله الامتحان حاجة تانية، فاتأكد من وضعه في دورتك.
- **الأسئلة "تدريبية أصلية"** اتكتبت للتطبيق ده، ومش منسوبة لـ ACCA ولا لأي جهة امتحان. لأسئلة امتحانات حقيقية استخدم مصادر مرخّصة.
- **البطاقات** ملخصات للمراجعة السريعة، ومش منهج كامل. المحتوى ما اتعملتلوش مراجعة فنية متخصصة.
- **مفيش مزامنة بين الأجهزة.** البنية جاهزة لها (معرفات ثابتة، وتوقيت تعديل، وإصدار للبيانات)، بس مفيش سيرفر. اعتمد على التصدير والاستيراد.
- **الإشعارات** بتشتغل طول ما الصفحة مفتوحة بس، ومفيش تنبيه بعد ما تقفلها. لما ترجع للصفحة، الجلسة بتتقفل بالوقت الصح.
